# NTC Thermistor Driver API reference {#mainpage}

The classes, functions and types of the HardFOC NTC thermistor driver, generated from the headers.

Start with NtcThermistor, the driver, and ntc::AdcInterface, the interface your platform port implements. The
configuration and reading structures are ntc_config_t and ntc_reading_t; errors are NtcError. The conversion
functions (Beta, Steinhart-Hart, voltage divider) are in the NTC namespace.

The guides, with examples that compile, are on the documentation site: <a href="../">NTC Thermistor Driver
documentation</a>.
